# PID Display 4 для Windows

Офлайн-симулятор пражского бортового информатора на Rust. В архиве один файл `PID-Display.exe`. Он открывает терминал водителя и запускает второй экземпляр того же файла для пассажирского LCD.

## Запуск

1. Распакуйте архив и запустите `PID-Display.exe`.
2. Выберите **Autobus** или **Tramvaj**. Троллейбусы находятся в разделе **Autobus**.
3. Введите номер на клавиатуре или экранной панели. Результаты обновляются при вводе. **Enter** или **Vyhledat** оставляют точные совпадения.
4. Нажмите на нужное направление и вариант рейса. Для очистки поиска нажмите **Smazat** или **Esc**.

При закрытии пульта закрывается и связанный пассажирский экран. Если экран закрыли отдельно, его можно открыть снова кнопкой **Otevřít displej**. Кнопка **LCD ⛶** меняет полноэкранный режим пассажирского окна. Для отдельного монитора перетащите окно туда перед включением полноэкранного режима.

## Пассажирские экраны

- **Автобус и троллейбус.** Серый LCD Čitelná Praha в духе пилота Solaris Urbino 10,5. Список прокручивается вверх при смене следующей остановки. У конечной отдельный экран выхода.
- **Трамвай.** Широкоформатный тёмно-синий LCD Bustec по фотографии Škoda 15T. Названия идут под углом вдоль горизонтальной линии. При отправлении полоса сдвигается влево и выделяет следующую остановку.
- Макеты адаптированы для обычного монитора Windows. Продолжительность и характер анимации реализованы для симулятора.

## Терминал водителя

| Кнопка | Что делает |
| --- | --- |
| **Potvrdit odjezd / Potvrdit příjezd** | Переключает этап поездки. Данные и озвучка обновляются сразу. |
| **Otevřít dveře / Zavřít dveře** | Управляет дверями в симуляции. При закрытии пассажирский LCD показывает предупреждение и звучит чешское объявление. Отправление доступно после закрытия. |
| **Vybrat zastávku** | Открывает список всех остановок рейса. Можно вручную выставить текущую остановку. |
| **Předchozí** | Возвращает на предыдущую остановку или отменяет текущий этап движения. |
| **Spustit / Pozastavit automatickou jízdu** | Включает или приостанавливает ускоренный автоматический режим. |
| **Hlášení zastávky / Ztlumit zvuk** | Повторяет объявление остановки или отключает звук. |
| **Změnit linku** | Возвращает к выбору транспорта, линии и направления. |

Встроены **42 трамвайные, 195 автобусных и 7 троллейбусных линий**. Включены городские линии, которые обслуживают хотя бы одну остановку в Праге по GTFS PID от 7 ноября 2026 года. По каждому направлению выбрано до трёх фактических вариантов пути. Среди них трамваи **5, 20** и автобусы **120, 130, 170**. Часы показывают местное время Windows. Минуты до остановок рассчитываются по симуляции маршрута. Маршруты являются снимками расписаний и могут отличаться от текущих объездов.

## Сборка

Установите [Rust для Windows](https://rust-lang.org/tools/install/). Для стандартного MSVC-варианта Rust нужны Visual Studio Build Tools с компонентами C++ и Windows SDK. Сборка проверена на Rust 1.90.0 GNU x64. В каталоге исходников выполните:

```powershell
cargo test --locked --offline
cargo build --release --locked --offline --bins
.\target\release\PID-Display.exe
```

Один EXE появится в `target\release`. Для сборки не нужны Cargo-зависимости, Python, модель озвучки или интернет. Встроенное демо-аудио уже есть в исходном архиве.

## Дополнительные линии

Скачайте [PID_GTFS.zip](https://data.pid.cz/PID_GTFS.zip). С установленным Python 3 выполните:

```powershell
python .\tools\import_gtfs.py .\PID_GTFS.zip 9 59 207 -o .\target\release\routes.tsv
```

Замените номера в примере на линии, присутствующие в вашем GTFS. Импорт выбирает самый частый вариант остановок для каждого направления. `--variants 3` добавит до трёх вариантов на направление. Положите `routes.tsv` рядом с EXE и перезапустите систему. Геолокация и онлайн-расписание для симуляции не используются.

## Озвучка

Чешские объявления используют **Supertonic 3 M1**. Для всей встроенной городской сети звук работает офлайн. Программа использует готовые реплики там, где они есть, и собирает остальные объявления из озвученных названий остановок и служебных фраз. Встроены отдельные гонги и предупреждение о закрытии дверей. Звук для новых импортированных остановок без совпадающего объявления использует чешский голос Windows, если он установлен.

Для подключения разрешённой записи положите файл `ID-событие.wav` или `ID-событие.mp3` в папку `audio` рядом с программами. ID остановки указан во второй колонке строки `stop` в `data/prague.tsv` или `routes.tsv`. События — `arrive` (прибытие), `next` (следующая остановка), `final` (конечная). Для предупреждения о дверях используйте `vehicle-door.wav` или `vehicle-door.mp3`. Программа воспроизводит файл целиком, поэтому гонг можно включить в саму запись.

Чтобы обновить встроенную сеть, выполните `python tools/import_gtfs.py PID_GTFS.zip --prague --variants 3 -o data/prague.tsv`. Затем установите Python-пакет `supertonic` и выполните `python tools/build_city_audio.py --cache .voice-cache`. Генератор скачает модель при первом запуске. Можно указать готовую модель через `--model path/to/supertonic-3`. После обновления данных и озвучки пересоберите EXE.
